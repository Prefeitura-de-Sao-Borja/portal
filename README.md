# Portal Oficial - Prefeitura de São Borja

Projeto de desenvolvimento do portal oficial da Prefeitura Municipal de São Borja, uma plataforma moderna e acessível para apresentação de informações públicas e serviços aos cidadãos.

## 📋 Sobre o Projeto

Este repositório contém o código-fonte do portal público da Prefeitura de São Borja. O projeto visa modernizar a presença digital da administração municipal, oferecendo uma interface intuitiva e responsiva para acesso a informações, serviços e comunicação com os cidadãos.

## 🛠️ Tecnologias Utilizadas

- **TypeScript** - 64.2% | Linguagem de programação principal com tipagem estática
- **JavaScript** - 23.7% | Lógica e interatividade do lado do cliente
- **PLpgSQL** - 9.7% | Scripts e funções de banco de dados
- **Shell** - 1% | Scripts de automação e deploy
- **PowerShell** - 0.9% | Scripts de gerenciamento
- **CSS** - 0.5% | Estilização e design responsivo
